## Lưu ý
- File 01–14: mỗi cung có **map con riêng** → import đúng map theo link.
- File 15–19 (Tour 3 ngày + 4 Tour kết nối): hiện **chưa tạo map con riêng** → trên web/QR đang trỏ về map TỔNG. Nếu muốn tách, anh tạo 5 map con mới rồi gửi mid, em wire lại.
- Mỗi file KML cung chi tiết gồm: **đường tuyến + các điểm dừng có thuyết minh** (popup mô tả). Layer điểm đến tổng (ẩm thực, lưu trú, cảnh quan, di tích, di sản, trải nghiệm) đẩy riêng vào map TỔNG từ thư mục `diem-den/`.
